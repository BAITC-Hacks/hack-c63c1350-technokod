# Фирменный стиль WindAgent

Стиль решения для прогнозирования выработки ВЭС. Тон — промышленная энергетика: сдержанный, инженерный, без глянца. Все числа ниже измерены, а не подобраны на глаз: контраст считается по формуле WCAG, палитра рядов данных проверена валидатором из навыка `dataviz`, различимость при дальтонизме — симуляцией Machado–Oliveira–Fernandes (2009).

## Знак

Знак — ротор ветроустановки из трёх лопастей на скруглённом поле. Ротор выбран потому, что он и есть объект прогноза: это единственная форма, которую диспетчер узнаёт мгновенно и которая не требует пояснений. Лопасти сужаются от комля к законцовке и закручены на 6,5°, как у настоящей машины, а не нарисованы симметричными лучами — из-за этого знак читается как техника, а не как абстрактная вертушка. Одна лопасть окрашена акцентным янтарным: это отметка текущего выпуска прогноза, ротор в работе.

Геометрия посчитана параметрически (хорда, закрутка, радиусы), поэтому знак легко пересобрать под другой размер без ручной правки кривых.

| Файл | Назначение |
|---|---|
| `assets/brand/mark.svg` | знак 64×64, поле `#124A6E` — для светлых поверхностей |
| `assets/brand/mark-dark.svg` | то же, поле `#1A6B9B` — для тёмных поверхностей, иначе тонет в фоне |
| `assets/brand/logo.svg` | горизонтальная связка знак + слово, тёмное слово |
| `assets/brand/logo-dark.svg` | связка для тёмного фона |
| `assets/brand/favicon.svg` | плотный вариант ротора: шире хорда, меньше закрутка — под 16–32 px |
| `assets/brand/favicon-32.png` | растровая иконка вкладки |
| `assets/brand/apple-touch-icon-180.png` | иконка для домашнего экрана iOS |

Слово «WindAgent» набрано Segoe UI Semibold и переведено в кривые: внешние шрифты не загружаются, начертание не зависит от машины. Все SVG содержат `viewBox`, размеры файлов — от 2,9 до 6,7 КБ.

**Проверено:** знак различим с 16 px (три лопасти и акцент видны), уверенно читается с 24 px. Минимальный размер — 16 px для `favicon.svg`, 24 px для `mark.svg`. Охранное поле вокруг знака — не меньше 1/4 его стороны. Нельзя: менять углы между лопастями, красить более одной лопасти акцентом, растягивать непропорционально, накладывать знак на фотографию без плашки, перекрашивать поле в цвета, не входящие в палитру.

## Цвета данных

Рядов ровно два — турбина 1 и турбина 2. Эталоны (климатология, персистентность, константа) не являются рядами равного веса: они рисуются приглушённым нейтральным пунктиром, чтобы не конкурировать с прогнозом.

| Роль | Переменная | Светлая | Тёмная |
|---|---|---|---|
| Турбина 1 | `--series-1` | `#1A6B9B` | `#2E8DC2` |
| Турбина 2 | `--series-2` | `#C87C00` | `#C87C00` |
| Полоса P10–P90 | `--band` | `#1A6B9B` при 14 % | `#2E8DC2` при 18 % |
| Эталоны, факт | `--ref` | `#6B7C88`, пунктир | `#8697A3`, пунктир |

Результат валидатора (`scripts/validate_palette.js` из навыка `dataviz`, режим `--pairs all`):

| Проверка | Светлая, поверхность `#FFFFFF` | Тёмная, поверхность `#151D23` |
|---|---|---|
| Полоса светлоты OKLCH | PASS | PASS |
| Порог цветности | PASS | PASS |
| Различимость при дальтонизме | PASS, ΔE 22,0 (протанопия) | PASS, ΔE 21,6 (протанопия) |
| Различимость при обычном зрении | PASS, ΔE 28,9 | PASS, ΔE 26,3 |
| Контраст к поверхности | PASS, 5,80:1 и 3,31:1 | PASS, 4,63:1 и 5,15:1 |

Симуляция дальтонизма отдельной проверкой: протанопия даёт `#546c9d` против `#958200` (ΔE 21,9), дейтеранопия — `#43609a` против `#a79406` (ΔE 28,8). Пара различима в обоих случаях с большим запасом при пороге 8.

**Чёрно-белая печать — ограничение, которое надо знать.** Яркости рядов: 0,131 и 0,267 в светлой теме, контраст между рядами 1,75:1; в тёмной теме 0,235 и 0,267, всего 1,11:1. Цвета мало, поэтому в монохроме идентичность ряда обязана нести вторая кодировка: турбина 1 — сплошная линия, турбина 2 — штриховая 6/3, плюс прямые подписи рядов у правого края. Это же правило страхует и forced-colors.

Если когда-нибудь понадобится третий ряд — `#1BAF7A` на светлой и `#199E70` на тёмной. Проверено: тройка проходит все жёсткие пороги, но на тёмной теме худшая пара при обычном зрении даёт ΔE 15,0 при пороге 15, то есть впритык. Третий ряд допускается только с прямой подписью.

## Типографика

Системный стек, никаких внешних загрузок:

```css
--font: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-mono: ui-monospace, SFMono-Regular, "Cascadia Mono", Consolas, monospace;
```

| Уровень | Размер / интерлиньяж | Начертание |
|---|---|---|
| Заголовок страницы | 34 / 40 px | 650 |
| Раздел | 22 / 28 px | 600 |
| Подраздел | 17 / 24 px | 600 |
| Основной текст | 15 / 24 px | 400 |
| Подпись, легенда | 13 / 18 px | 500 |
| Микроподпись, ось | 11 / 14 px | 500 |
| Крупное число | 40 / 44 px | 600 |

Числа в таблицах, на осях и в колонках метрик — `font-variant-numeric: tabular-nums`, иначе цифры пляшут по вертикали. Отдельно стоящее крупное число берёт пропорциональные цифры. Единицы измерения всегда подписаны словом рядом со значением, а не только в заголовке колонки.

## Сетка и поверхности

- Базовая единица 4 px, шаг отступов 4 / 8 / 12 / 16 / 24 / 32 / 48.
- Ширина содержимого 1120 px, узкая колонка текста — 720 px.
- Радиусы: 6 px у элементов управления, 12 px у карточек, 14 px у поля знака.
- Границы 1 px, `--border`. Тень одна и мягкая: `0 1px 2px rgba(16,25,31,.06), 0 8px 24px rgba(16,25,31,.06)`; в тёмной теме тени не используются, разделение идёт границей.
- Линии графиков 2 px, сетка 1 px, точки не меньше 8 px, у наложенных элементов кольцо 2 px цветом поверхности.

## Как пересобрать

Знак, логотип и иконки собираются скриптом-генератором: геометрия лопасти задана параметрами (радиусы комля и законцовки, ширина хорды, закрутка), слово переводится в кривые из системного шрифта. Проверка палитры — валидатором из навыка `dataviz`, контраст и симуляция дальтонизма — арифметикой по формулам WCAG и Machado–Oliveira–Fernandes.
