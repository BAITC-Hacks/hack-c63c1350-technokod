# Качество модели

Числа взяты из `docs/metrics.json`, файл перезаписывается при каждом обучении (`python -m app.cli train`).

## Протокол измерения

Проверка воспроизводит рабочий режим: для каждого дня января 2026 берётся прогноз погоды,
который был доступен **на этот день**, и по нему считается выработка на 48 часов вперёд.
Факт погоды не используется ни в обучении, ни в проверке; факт выработки участвует только как
эталон при сравнении. Январь 2026 в обучение не входит.

- Горизонт 24 ч — часы 1–24 (прогноз погоды, выпущенный за сутки, lead 1), 720 часов января.
- Горизонт 48 ч — часы 25–48 (прогноз, выпущенный за двое суток, lead 2), 720 часов.
- Мощность нормирована на номинал (0..1), поэтому MAE в долях номинала, а nMAE = MAE × 100 %.

## Веса смеси

Подбираются на той же честной валидации, отдельно по турбине:

| Турбина | кривая мощности | двухстадийная | бустинг |
|---|---|---|---|
| 1 | 0.5 | 0.5 | 0.0 |
| 2 | 0.6 | 0.4 | 0.0 |

Прямой бустинг «признаки прогноза → мощность» переобучается на исторические совпадения и на
честной проверке проигрывает обеим физическим моделям, поэтому его вес равен нулю: в рабочем
прогнозе он остаётся только как отдельная колонка для сравнения.

## Сравнение с эталонами

Эталоны посчитаны независимо на том же периоде и том же горизонте 24 часа (январь 2026, 720 часов),
методика и код проверки — в `docs/validation.md`.

| Метод | Т1, MAE | Т2, MAE | Насколько модель лучше |
|---|---|---|---|
| **смесь (рабочая модель)** | **0.1431** | **0.1455** | — |
| климатология по часу суток | 0.3003 | 0.3007 | на 52 % |
| константа: средняя выработка за историю | 0.3010 | 0.3017 | на 52 % |
| персистентность: последние полные сутки | 0.3568 | 0.3463 | на 58–60 % |

Персистентность на суточном горизонте хуже простой константы: выработка ВЭС за сутки почти не
коррелирует со вчерашней. Отсюда практический вывод — лаги фактической выработки в признаках
бесполезны, и их отсутствие не является упущением.

## Интервал неопределённости

К точечному прогнозу считается интервал P10–P90 по квантилям остатков, раздельно для горизонтов
24 и 48 часов и для четырёх уровней прогнозной мощности (штиль, разгон, рабочая зона, номинал):
ошибка в середине кривой мощности в разы больше, чем на штиле и на полке.
Фактическое покрытие интервала на январе 2026 — **79.6 %** при целевых 80 %. Оценка оптимистична по
построению: квантили подобраны на том же месяце, на котором измерено покрытие; независимая проверка —
в `docs/validation.md`.

## Как повторить

```bash
# Windows
.venv\Scripts\python.exe -m app.cli train     # перечитает данные, переобучит, перезапишет docs/metrics.json
.venv\Scripts\python.exe -m app.cli report    # печатает эти же числа из docs/metrics.json

# Linux / macOS
.venv/bin/python -m app.cli train
.venv/bin/python -m app.cli report
```

Обучение двух турбин занимает около 15 секунд и не требует сети: архивные прогнозы лежат в
`data/cache/weather/`. Эталонное окружение — Python 3.14, pandas 3.0.6, scikit-learn 1.9.1.
