# Анализ ТЗ и данных

## ТЗ
- Горизонт 24–48 часов, шаг час, две турбины (координаты 43.645150, 78.535604 и 43.643198, 78.538828, Шелекский ветровой коридор, Алматинская область).
- История: 11.03.2023 – 31.01.2026. Тест: 01.02 – 28.02.2026. Фактов за февраль в выданных данных нет, их держит постановщик. Оценка будет по нашему прогнозу против скрытого факта.
- Ключевое требование: для каждого дня использовать прогноз погоды, который был доступен в тот момент, а не факт. Нарушение этого требования = несоответствие задаче.
- Обязательный формат: Agentic AI с полным циклом «погода → подготовка → модель → прогноз → анализ → пересчёт при обновлении».
- Баллы: соответствие 25, техника 25, README и воспроизводимость 25, ценность 15, оригинальность 10. README и воспроизводимость весят столько же, сколько сама модель.

## Данные
- 10-минутные записи: время, средняя скорость ветра (м/с, датчик гондолы), нормализованная активная мощность 0..1, температура °C. Пропусков в значениях нет, есть пропуски по времени.
- T1: 142 360 строк, 31 разрыв больше часа, суммарно 1 658 часов, самый большой 41 день (28.06–17.07.2024 и далее до 05.08.2024). T2: 149 499 строк, 68 разрывов, 450 часов.
- Кривая мощности чистая: до 3 м/с ~0, 3–11 м/с рост, с 11–12 м/с полка 0.95–0.99, отключения по сильному ветру не наблюдалось (макс 23 м/с). Средний коэффициент использования 0.37, зимой выше (0.45–0.52 в ноябре–декабре), летом ниже (0.23–0.30).
- Часовая агрегация: 25 392 часа, из них без факта T1 1 629, T2 388.
- Турбины стоят в 400 м друг от друга, погода одна на обе, различаются только кривые мощности и простои.

## Источник архивных прогнозов
Open-Meteo Previous Runs API (`previous-runs-api.open-meteo.com`): для каждого часа поля `*_previous_day1` и `*_previous_day2` содержат значение из прогноза, выданного за 1 и 2 дня до этого часа. Это и есть «прогноз, доступный на момент». Проверено: за 2025 год 8 760 часов без пропусков, за 2023 данных нет. Для обучения на 2023–2024 используется Historical Forecast API (архив прогнозных моделей, лид 0–24 ч). Единицы: скорость км/ч, переводится в м/с.
