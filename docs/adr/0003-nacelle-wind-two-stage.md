# ADR 0003. Ветер гондолы — промежуточная цель обучения, а не признак

Статус: принято, реализовано (`app/model.py`, компонент `two_stage`).

## Контекст

В данных организаторов есть скорость ветра по датчику гондолы — величина, которая связана с мощностью
почти однозначно (кривая мощности по ней заметно чище, чем по прогнозной скорости на 100 м). Но на момент
выпуска прогноза этой величины не существует: она измеряется в тот час, который мы прогнозируем.

## Варианты

1. Использовать ветер гондолы как признак модели. Запрещено: это факт прогнозируемого часа, утечка.
2. Игнорировать его полностью и учить только «прогноз погоды → мощность».
3. Разделить задачу на два шага: «прогноз погоды → ветер гондолы» (обучаемо, шумно) и «ветер гондолы →
   мощность» (почти детерминированная измеренная зависимость).

## Решение

Двухшаговый компонент: `wind_gbm` предсказывает скорость ветра на гондоле по тем же 16 прогнозным
признакам, затем `nacelle_curve` (эмпирическая кривая по измерениям турбины, бин 0.25 м/с) переводит эту
величину в мощность. На инференсе ветер гондолы нигде не берётся из данных — он всегда предсказан.
Промежуточная величина сохраняется в выпуске как `wind_nacelle_pred` и годится для диагностики.

## Последствия

- Утечки нет: измеренный ветер гондолы участвует только как цель обучения на исторических часах.
- На итоговом обучении компонент `two_stage` по одиночке уступает кривой мощности на обеих турбинах
  (T1 — nMAE 14.93 % против 14.71 %, T2 — 15.26 % против 14.80 % на горизонте 24 ч), но заметно
  превосходит прямой бустинг и хорошо дополняет кривую в смеси: веса 0.5 на T1 и 0.4 на T2. Разница
  между турбинами ожидаема — у них разные простои и разное качество датчика.
- Ценность компонента именно в смеси: он ошибается не там, где кривая, поэтому даёт выигрыш, которого
  ни один из них не даёт в одиночку.
- Цена решения — вторая обучаемая модель и накопление ошибки двух шагов, поэтому компонент работает
  только в смеси, а не сам по себе.
- Часы без показаний гондолы исключаются из обучения этого компонента (`dropna(subset=["wind_ms"])`).
