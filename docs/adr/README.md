# Журнал архитектурных решений

Каждое решение записано в формате ADR: контекст → варианты → решение → последствия. Решения описывают
фактический код репозитория; при изменении кода правится и соответствующий ADR.

| № | Решение | Где реализовано |

| [0003](0003-nacelle-wind-two-stage.md) | Ветер гондолы — промежуточная цель обучения, а не признак | `app/model.py` |

| [0005](0005-cache-in-repo.md) | Кэш внешних вызовов хранится в репозитории | `app/weather.py` |
